# 截图说明

这里放 README 用到的界面截图。三张图，按下面清单命名后直接放进本目录，README 会自动引用。

| 序号 | 文件名 | 拍什么 | 为什么需要它 |
|---|---|---|---|
| 1 | `screenshot-chip.png` | 输入框内、模型选择器**左侧**的分支徽标。截出整条输入框，能看到徽标 + 「发消息或创建任务」占位文字 + 模型选择器 | 这是插件最常被看到的样子，让人一眼明白「它长在输入框里」 |
| 2 | `screenshot-panel.png` | 点徽标后的完整面板。能同时看到「提交改动」「合并到指定分支」「分支」三张卡片 | 展示主功能：提交与合并 |
| 3 | `screenshot-conflict.png` | 有冲突时的红色卡片：标题「有冲突待处理」+ 文件清单 + 三个按钮 | 冲突处理是本插件最有差异化的能力 |

## 拍摄建议

- **宽度**：1280–1600px 之间，2 倍缩放下截图更清晰。
- **主题**：用浅色主题截一张即可；如果愿意，第 2 张可以再补一张深色版命名 `screenshot-panel-dark.png`。
- **隐私**：截图前确认分支名、文件路径里**没有真实项目信息**。建议在一个测试仓库里操作，分支名用 `feature/user-login` 这类示例。
- **格式**：PNG，单张控制在 300 KB 以内（GitHub 对 README 图片会自动优化，但过大的原图会让页面变慢）。

## 拍完后

1. 把三个 PNG 放进本目录（文件名严格按上表）。
2. README 的「截图」一节已经写好了引用，图片存在即显示。
3. 提交：

```sh
git add docs/*.png README.md
git commit -m "docs: 补充界面截图"
git push
```

> 注：如果只想先放一两张，把没有的那张从 README 的 `<img>` 里删掉即可，避免出现破图。
